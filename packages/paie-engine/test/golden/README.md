# Tests golden

Un fichier JSON par bulletin validé par l'expert-comptable : entrées (salarié, variables,
période), règles appliquées, et résultat attendu au franc près (net à payer, coût employeur,
chaque ligne).

**Uniquement des bulletins anonymisés.** Aucun nom, n° CNPS, NIU ou IBAN réel.

Le lanceur `golden.test.ts` sera écrit en phase 3, quand le pipeline complet existera.
